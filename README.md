# ☕ Brew & Bloom — Café Landing Page

> **Good coffee. Slow mornings. Better moments.**

A modern, responsive and conversion-focused café landing page designed to give local cafés a strong online presence and make it easy for customers to explore the menu, find the café and get in touch.

## 🎯 Purpose

The website was designed with **local café marketing** in mind.

Instead of simply displaying information, the landing page focuses on converting visitors into customers through clear calls-to-action such as:

* **View Menu**
* **Visit Us**
* **WhatsApp Us**
* **Get Directions**
* **Plan Your Visit**

## 🎬 Animations & Interactions

The website uses subtle animations to create a polished experience without affecting usability.

### Page Load

* Staggered hero text animation
* Smooth hero image reveal
* Animated CTA buttons

### Scroll Animations

Sections smoothly fade and slide into view as the user scrolls.

### Hover Effects

* Menu cards lift slightly
* Food images zoom smoothly
* Gallery images reveal an overlay
* Buttons have subtle lift/press interactions
* Navigation links animate on hover

### Additional

* Sticky navbar on scroll
* Scroll progress indicator
* Smooth page navigation
* Mobile-friendly animations
* `prefers-reduced-motion` support

## 🎨 Design Philosophy

The design follows a simple principle:

> **Premium doesn't have to mean complicated.**

The interface uses:

* Warm café-inspired colors
* Generous whitespace
* Clean typography
* Rounded imagery
* Minimal decorative elements
* Subtle animations
* Strong visual hierarchy

The goal is to make the website feel **warm, trustworthy and premium** while keeping the user journey simple.

---

## 🔧 Customization

The template can easily be customized for a real café.

You can replace:

* Café name
* Logo
* Menu items
* Prices
* Food images
* Address
* Phone number
* Opening hours
* Google Maps location
* WhatsApp number
* Instagram link
* Customer reviews

This makes the project suitable as a **reusable café website template**.
